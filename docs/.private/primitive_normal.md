# 正準形の法線をワールド空間に戻す

交差判定を正準ローカル空間へ移すと（[primitive_intersection.md](primitive_intersection.md)）、法線もローカル空間で出ることになる。
これをワールド空間へ戻すとき、点や方向に使う `to_world` をそのまま掛けてはいけない。

本ドキュメントでは、法線だけ別の行列が要る理由と、その行列を追加で持たずに済ませる方法をまとめる。

## 1. なぜ法線だけ変換が違うのか

法線は「向き」ではなく「面に垂直であるという関係」で決まる量である。
点や方向は変換後の位置がそのまま答えになるが、法線は変換後も面に垂直でなければ意味を持たない。

面に沿う接ベクトル `t` は、点の差なので線形部 `M` で素直に移る。

```
t_world = M t_local
```

法線 `n` は接ベクトルと直交する。

```
n_local ・ t_local = 0
```

ワールド空間でも直交していてほしいので、求める行列 `A` は次を満たす必要がある。

```
(A n_local) ・ (M t_local) = n_localᵀ Aᵀ M t_local = 0
```

これが面上のすべての接ベクトルについて成り立つ条件は `Aᵀ M = I`、すなわち次になる。

```
A = (M⁻¹)ᵀ
```

これを逆転置行列と呼ぶ。

`M` が回転だけなら `M⁻¹ = Mᵀ` なので `A = M` となり、法線も点と同じ行列で移る。
差が出るのは、`M` にスケールが入っているときである。
しかも等方スケールなら向きは変わらず、大きさが変わるだけで正規化に吸収される。

つまり問題になるのは非等方スケールに限られる。
この設計では `t_primitive` が形状の寸法をスケールに焼き込んでいるので（[hyperboloid.md](hyperboloid.md)）、半径と高さが違う円柱や円錐は常に非等方である。
ここを `to_world` で済ませると、そうした形状の法線だけが静かに傾き、陰影がわずかにずれる。

## 2. 行列を追加で持たなくてよい

`to_local` は `M⁻¹` そのものである。
したがって逆転置は、`to_local` の線形部を転置するだけで得られる。

```c
inv = mat3_from_mat4(&(prim->to_local));
normal = vec3_normalize(mat3_mul_transposed(&inv, n_local));
```

`mat3_mul_transposed()` は転置行列を組み立てずに、各列との内積として計算する。
`t_mat3` は基底を列に持つので（[matrix.md](matrix.md)）、転置した積は列方向の内積になる。

正規化するため、逆転置に掛かる定数倍は結果に影響しない。

## 3. 正準形ごとのローカル法線

二次曲面5種は、陰関数 `pᵀQp = 0` の勾配がそのまま法線になる。

```
∇(pᵀQp) = 2Qp
```

係数の 2 は正規化で消えるので、`Qp` の xyz 成分をそのまま使う。
`Q` は型ごとの定数なので（[quadric.md](quadric.md) の `unit_quadric`）、形状ごとの値は入らない。

| 正準形 | ローカル法線 |
| --- | --- |
| `UNIT_SPHERE` | `(x, y, z)` |
| `UNIT_CYLINDER` | `(x, y, 0)` |
| `UNIT_CONE` | `(x, y, -z)` |
| `UNIT_HYPERBOLOID` | `(x, y, -z)` |
| `UNIT_PARABOLOID` | `(x, y, -1/2)` |

平面と円盤は二次曲面ではないので、勾配は使えない。
`z = 0` を `z² = 0` と書けば二次形式にはなるが、表面上で `∇Q = (0, 0, 2z)` がゼロになり、法線が出せなくなる。
この2つはローカル法線を定数 `(0, 0, 1)` とする。

## 4. 反転の判定はワールド空間で行う

レイと同じ向きを向いた法線は反転させる。

```c
if (vec3_dot(normal, ray->dir) > 0.0f)
	return (vec3_scale(-1.0f, normal));
```

この判定はワールド空間で行う。
ローカル空間の `n_local` と `d_local` で判定すると符号が変わりうるからである。
法線は逆転置で移るのに対し方向は線形部で移るので、非等方スケールのもとでは両者のなす角が変換で変わる。
内積の符号はその角が 90 度をまたぐかどうかで決まるため、どちらの空間で見るかによって結果が食い違う場合がある。
