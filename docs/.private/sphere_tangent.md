# 球面座標系のtangent（接線）を求める

## 0. 球面座標系

球面座標系は、3次元ユークリッド空間に定まる座標系の一つで、動径座標と二つの角度座標で表される極座標系である。
通常は動径座標に記号 r を用い、天頂角には θ を、方位角には φ を用いて表される。
動径座標は 0 ≤ r < ∞ の範囲にあり、天頂角は 0 ≤ θ ≤ π の範囲にある。
方位角の動く範囲は −π < φ ≤ π もしくは 0 ≤ φ < 2π のどちらかを用いることが多い。

球面座標 P(r,θ,φ) から直交直線座標 (x,y,z) への変換は

```
x = rsinθcosφ
y = rsinθsinφ
z = rcosθ
```

で与えられる。

---

## 1. θとφについて微分する

### 前提知識 `(sinθ)' = cosθ`, `(cosθ)' = -sinθ`

sinθをθについて微分する。

```
(sinθ)' = lim(δ->0)[(sin(θ+δ) - sinθ)/δ]
```

加法定理より、

```
sin(θ+δ) = sinθcosδ + cosθsinδ

(sinθ)' = lim(δ->0)[(sinθcosδ + cosθsinδ - sinθ)/δ]
        = lim(δ->0)[sinθ(cosδ - 1)/δ + cosθsinδ/δ]

lim(δ->0)[(cosδ - 1)/δ] = 0
lim(δ->0)[sinδ/δ] = 1

(sinθ)' = sinθ*0 + cosθ*1 = cosθ
```

よって、`(sinθ)' = cosθ`

cosθについても同様にして、`(cosθ)' = -sinθ`

なお、これらが成り立つのは θ がラジアンのときのみである。
`lim[sinδ/δ] = 1` は「単位円では弧の長さ＝角度」というラジアンの定義に依存している。

### `∂P/∂θ` (θについて微分する)

```
∂P/∂θ = (rcosθcosφ, rcosθsinφ, -rsinθ)
      = r(cosθcosφ, cosθsinφ, -sinθ)
```

大きさ `r` で割って正規化

```
e_θ = (∂P/∂θ)/r = (cosθcosφ, cosθsinφ, -sinθ)
```

### `∂P/∂φ` (φについて微分する)

`P.z = rcosθ` に φ は含まれないため、z成分は 0 になる。

```
∂P/∂φ = (-rsinθsinφ, rsinθcosφ, 0)
      = rsinθ(-sinφ, cosφ, 0)
```

大きさ `rsinθ` で割って正規化

```
e_φ = (∂P/∂φ)/(rsinθ) = (-sinφ, cosφ, 0)
```

括り出した係数と長さが一致するとは限らないため、正規化のたびに長さを確認すること。
ここでは括弧内のベクトルがいずれも長さ 1 だったため一致している。

### `(u,v,w)` 基底での成分

```
e_θ = (cosθcosφ, cosθsinφ, -sinθ)
e_φ = (-sinφ, cosφ, 0)
```

これらは球のオブジェクト空間の基底 `(u, v, w)` を軸とする成分である。
`(u, v, w)` がワールド軸と一致する場合に限り、そのままワールド座標の成分となる。
一般形は次章で扱う。

## 2. 点PのT(tangent),B(bitangent)を求める

- 点Pの法線 `N (normal)`
- 球のオブジェクト空間の基底 `(u, v, w)`

```
φ = atan2(N・v, N・u)
θ = acos(N・w)

T = (-sinφ * u) + (cosφ * v)
B = (cosθcosφ * u) + (cosθsinφ * v) + (-sinθ * w) = T×N
```

`atan2` は `atan2(y, x)` の順に引数を取る。
`N・u = sinθcosφ` が x、`N・v = sinθsinφ` が y にあたるため、この順序になる。

θ の算出には `asin` より `acos` が望ましい。
`asin` は引数が ±1 付近、すなわち極で誤差が増幅されるのに対し、
`acos` の精度が落ちるのは赤道付近であり、面積の大きい領域を優先できる。

B の符号は UV の向きの規約に依存する。
ここでは `T×N` が正しいが、`N×T` になる規約もある。
赤道の φ=0 のような具体的な1点を取り、v が増える方向と一致するか確認するのが確実である。

---

## 3. T(tangent)の計算から三角関数の往復をなくす

`atan2` で角度を求め、`sin`/`cos` で戻す処理は往復になっている。
N を u,v 平面に射影し、90度回転することで、角度を経由せずに導出できる。

```
tu = N・u = sinθcosφ    // Nのu軸への射影（成分）
tv = N・v = sinθsinφ    // Nのv軸への射影（成分）
len = sqrt(tu^2 + tv^2) = sinθ    // Nをuv平面に射影した影の長さ

cosφ = tu/len, sinφ = tv/len

(tu, tv) を90度回転すると (-tv, tu)

T = -sinφ * u + cosφ * v
  = (-tv * u + tu * v) / len
B = T×N
```

2次元ベクトルの90度回転は `(x, y) -> (-y, x)` であり、角度の算出を必要としない。
`atan2` が返した角度は `sin`/`cos` によって元の成分に戻されるだけであるため、
射影した成分をそのまま使えばよい。

`len` は N を uv 平面に落とした影の長さであり、その緯度の円の半径に等しい。
赤道で 1、極で 0 となる。

### 極の扱い

極では `len = sinθ = 0` となり、T が定義できない。
緯線が点に潰れ、接線が引けないためである。

```
if (len < ε)
    T = u    // 極では正しい T が存在しないため
```

これはゼロ除算を防ぐためのものであり、正しい向きを返すものではない。
球面全体に連続な接ベクトル場を張ることは不可能であり（毛玉の定理）、
経度緯度によるパラメータ化では、その特異点が極に現れる。
